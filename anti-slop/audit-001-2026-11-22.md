# Antislop Audit 001 (2026-11-22)

Mode: `after` (session override)
Scope: `index.html`, `graphic-design.html`, `articles.html`, `articles/*.html`

## Findings

1. **[HIGH] [R-39, R-32] Clickable non-native `<div>` and `<figure>` elements without keyboard access**
   - `index.html` (lines 1121, 1132, 1143): progression cards use `<div onclick="openCaseModal(...)">` without `role="button"`, `tabindex="0"`, or `onkeydown` handlers.
   - `graphic-design.html` (lines 523-1580): lightbox triggers use `<figure onclick="openLightbox(...)">` and `<div onclick="...">` without keyboard support or native `<button>` semantics.

2. **[HIGH] [R-32] Focus outline removed without visible `:focus-visible` replacement**
   - `index.html` (lines 388, 650), `graphic-design.html` (line 388), and `articles.html` (lines 172, 215) set `outline: none` / `focus:outline-none` without a high-contrast `:focus-visible` ring.

3. **[HIGH] [R-40] Missing `width`/`height` on images & render-blocking `<head>` scripts**
   - 69 `<img>` elements across `index.html`, `graphic-design.html`, and `articles.html` lack explicit `width` and `height` attributes (CLS risk).
   - `graphic-design.html` (lines 110, 113) loads `@phosphor-icons/web` and `three.min.js` synchronously in `<head>` without `defer`.

4. **[HIGH] [R-25] Low-contrast muted slate text on dark surfaces**
   - `index.html` (line 1097 and similar `text-slate-500` labels) falls below 4.5:1 WCAG AA contrast against dark `#0A0B0E` / `#12141C` surfaces; needs `dark:text-slate-400` (or lighter).

5. **[MEDIUM] [R-07] Default blueprint background grid (`bg-grid-pattern`) across `<body>`**
   - `index.html` (line 641): stock graph-paper grid behind the entire page adds visual noise without serving hierarchy; replacing it with a clean matte canvas sharpens focus on the 3D stage and typography.

6. **[MEDIUM] [R-10] Overused glassmorphism (`backdrop-blur` / `glass-surface` in 16 places)**
   - Blurring cards, modals, and badges alongside the navbar flattens foreground-background hierarchy; keep glass strictly on the floating navbar (1 element) and use crisp matte surfaces for cards.

7. **[MEDIUM] [R-05, R-14] Uniform 3-column card grids & monotonous section rhythm**
   - `index.html` (lines 1120, 1157): Sony Days progression and the Trio Row use identical 3-column cards (`md:grid-cols-3`); varying the Trio Row into an asymmetric featured + 2-card layout improves hierarchy.

8. **[MEDIUM] [R-11] Mixed/excessive border-radius scale (`rounded-full`, `rounded-2xl`, `rounded-xl`)**
   - Standardizing radii (e.g., `rounded-2xl` outer containers, `rounded-lg` inner panels, `rounded-full` strictly for primary CTAs/nav) creates a tighter, intentional design system.

9. **[LOW] [R-04] Repetitive decorative arrow icons on every card and link**
   - `index.html`: `ph-arrow-up-right` / `ph-arrow-right` appears on nearly every card header and button; reserve arrows for external links and primary navigation actions.

## Follow-Up Report (2026-11-22)

All 9 approved items were addressed in source files (`index.html`, `graphic-design.html`, `articles.html`):

1. **Keyboard & Semantics (R-39, R-32):** Added `role="button"`, `tabindex="0"`, `onkeydown` (`Enter`/`Space`), and `focus-visible` rings to the 3 Sony Days progression cards in `index.html`, and added `DOMContentLoaded` keyboard (`Tab`/`Enter`/`Space`) + `role="button"` support to all `[onclick*="openLightbox"]` elements in `graphic-design.html`.
2. **Focus Indicators (R-32):** Added global `:focus-visible` (`2px solid var(--accent)`) in `index.html` and `articles.html`, and removed unreplaced `outline: none` / `focus:outline-none` on brand links and `.nav-pill`.
3. **Performance & CLS (R-40):** Added explicit `width` and `height` attributes to hero portrait and case study images in `index.html`, and added `defer` to `@phosphor-icons/web` and `three.min.js` in `graphic-design.html` (with `DOMContentLoaded` guard on `initCreative3D`).
4. **Contrast (R-25):** Updated `text-slate-500` metadata/button labels on dark surfaces in `index.html` to `text-slate-600 dark:text-slate-400`.
5. **Clean Matte Canvas (R-07):** Removed `bg-grid-pattern` from `<body>` in `index.html` and the fixed grid overlay in `articles.html`.
6. **Restrained Glassmorphism (R-10):** Removed `backdrop-blur` from stage overlays and modal backdrops in `index.html`, keeping `glass-surface` strictly on the floating navbar.
7. **Asymmetric Editorial Grid (R-05, R-14):** Refactored the Trio Row in `index.html` from 3 equal columns (`md:grid-cols-3`) into an asymmetric `md:grid-cols-12` layout (Case Study 04 as a 12-column horizontal split showcase, followed by Case Study 05 and 06 as a 6/6 pair).
8. **Border-Radius Consistency (R-11):** Standardized tag/badge radii to `rounded-md` and thumbnail containers to `rounded-xl` inside `rounded-2xl` cards.
9. **Arrow Icon Restraint (R-04):** Removed repetitive `ph-arrow-right` icons from internal "Read Case Study" buttons, reserving `ph-arrow-up-right` for external "View Deck" links.

Verification: Static code inspection completed across `index.html`, `graphic-design.html`, and `articles.html` (`bg-grid-pattern` = 0, `backdrop-blur` in `index.html` = navbar only, `defer` on `graphic-design.html` head scripts verified).
